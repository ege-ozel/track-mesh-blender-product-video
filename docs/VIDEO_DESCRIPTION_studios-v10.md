# TrackMesh — studios-v10 description

Share DAW projects, PC to PC.

Windows only. The two PCs connect directly while both are online; at least one of them needs a reachable connection. There is no relay server yet.

Concept visualization with synthetic example data. The DAW backdrop is conceptual. The VST3 pictures were captured in an isolated SDK editor host with a synthetic local status fixture; they do not demonstrate operation in a real DAW. Desktop cards and the confirmation have been reflowed for each video format. The confirmation is a reconstruction, not a native Windows screen recording.

Save → Share → Sharing → Shared is an illustrated sequence. Share does not require closing the DAW project. The instruction to close the project belongs to the Get confirmation. No actual project transfer or DAW save validation was performed for these films.

Only the changed parts travel. Example: 44 MB new in a 1.6 GB project. This is synthetic new-data content, not a measured transfer, a speed claim, or a total network byte count. Progress is computed over the whole project, including reused data. **In this example**, progress starts near 100% because most data is reused. The remaining-data states are 44.0 MB / 97%, 29.0 MB / 98%, and 11.0 MB / 99%. The edit timing does not measure how long a real transfer takes.

Both films are silent. Ready for final review; not approved for publication.

## Türkçe açıklama

DAW projelerini bilgisayardan bilgisayara paylaş.

Yalnızca Windows için. İki bilgisayar da çevrimiçiyken doğrudan bağlanır; en az birinin bağlantısının karşı taraftan erişilebilir olması gerekir. Henüz relay sunucusu yoktur.

Görüntüler örnek verilerle hazırlanmış konsept görselleştirmesidir. DAW arka planı temsildir. VST3 görüntüleri, yalıtılmış SDK editör hostunda sentetik yerel durum verileriyle yakalanmıştır; gerçek DAW içinde çalışma kanıtı değildir. Masaüstü kartları ve onay penceresi her video oranı için yeniden yerleştirilmiştir. Onay, gerçek native Windows ekran kaydı değildir.

Save → Share → Sharing → Shared sırası temsili olarak gösterilir. Share için DAW projesini kapatmak gerekmez. Projeyi kapatma talimatı Get onayında kalır. Bu filmler için gerçek proje aktarımı veya DAW kaydetme doğrulaması yapılmadı.

1,6 GB projede 44 MB yeni veri bir örnektir; ölçülmüş aktarım, hız veya toplam ağ trafiği miktarı değildir. Yüzde, yeniden kullanılan veri dahil bütün proje üzerinden hesaplanır. **Bu örnekte**, verinin büyük bölümü yeniden kullanıldığı için yüzde %100'e yakın başlar. Kalan veri durumları 44,0 MB / %97, 29,0 MB / %98 ve 11,0 MB / %99'dur. Kurgu süreleri gerçek aktarım süresi ölçümü değildir.

İki film de sessizdir. Son incelemeye hazırdır; yayın onayı verilmiş sayılmaz.
